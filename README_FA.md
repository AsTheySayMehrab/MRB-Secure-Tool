# ابزار امنیتی MRB v2.1 🔒

یک ابزار فوق امنیتی برای رمزنگاری فایل‌ها با استفاده از الگوریتم **AES-256-GCM سه لایه** و سیستم کلیدسازی پیشرفته **Scrypt** و **HKDF**.

## 🚀 قابلیت‌ها
- **رمزنگاری سه لایه:** هر فایل به صورت متوالی ۳ بار با ۳ کلید متفاوت رمزنگاری می‌شود.
- **امنیت AEAD:** استفاده از AES-256-GCM برای تضمین محرمانگی و سلامت داده‌ها.
- **مقاومت در برابر Brute-force:** استفاده از Scrypt با پارامترهای سنگین (N=2^20) برای جلوگیری از حملات سخت‌افزاری.
- **پردازش دسته‌ای:** قابلیت رمزنگاری یا رمزگشایی کل یک پوشه به صورت خودکار.
- **نوار پیشرفت:** نمایش وضعیت عملیات با استفاده از `tqdm`.
- **بررسی سلامت فایل:** استفاده از HMAC-SHA3-256 برای تشخیص هرگونه دستکاری در فایل.

📖 نحوه استفاده
برنامه را اجرا کنید:
python secure_file_tool.py

### مراحل کار:
1. **Create Key:** ساخت یک کلید جدید (فایل `.key`). این فایل را هرگز گم نکنید!
2. **Load Key:** بارگذاری کلید ساخته شده در برنامه.
3. **Encrypt:** انتخاب فایل یا پوشه برای رمزنگاری. فایل‌ها با پسوند `.MRB` ذخیره می‌شوند.
4. **Decrypt:** بازگردانی فایل‌های `.MRB` به حالت اصلی.

## 🛡 ساختار امنیتی
- **الگوریتم اصلی:** AES-GCM (رمزنگاری تایید شده).
- **لایه اول مشتق‌ساز کلید:** Scrypt (سخت‌گیر نسبت به حافظه).
- **لایه دوم مشتق‌ساز کلید:** HKDF برای تولید زیر-کلیدهای لایه‌های مختلف.
- **تغییر دهنده IV:** استفاده از XOR tweak برای امنیت بیشتر در هر لایه.
